SHOP SUPPORT

飲食店・小売店向け 発信支援サービス

お店の発信、まとめて引き受けます。

「新メニューや入荷の情報を、発信する時間がない」
「撮った写真や動画が、来店につながっているのか分からない」

SHOP SUPPORTは、メニューや商品の撮影から、ショート動画、
SNSでの発信までを、外部のチームとしてまとめて引き受けるサービスです。
お店の皆様が、接客や仕込み、仕入れといった
本来のお仕事に集中できる環境をつくります。

WHAT WE DO

メニュー・商品の撮影
料理やドリンク、商品、店内の様子を、お店へ伺ってまとめて撮影します。
ショート動画
調理や接客の様子、新商品の紹介などを、Reels・TikTok・YouTube Shorts向けに仕上げます。
新メニュー・入荷の発信
投稿文、ハッシュタグ、公開のタイミングまで設計し、情報を届けます。
来店への導線
地図、予約ページ、プロフィールのリンクなど、ご覧になった方がお店へ進める道筋を整えます。
振り返り
どの発信がご来店やお問い合わせにつながったかを整理し、次の発信に活かします。

STRENGTHS

お店の忙しさに合わせてつくる
撮影の時間帯や段取りは、仕込みや接客の妨げにならないように組み立てます。お店の皆様に無理のない形で、発信を続けられる状態をつくります。

お店に伺って、まとめて撮影
写真と動画を同じ日にまとめて撮影します。営業への負担を抑えながら、複数の発信に使える素材をそろえます。

撮って終わりにしない
公開後の反応を確かめ、次の発信に反映します。ご来店につながる発信を、回を重ねて育てていきます。

FLOW

1. ヒアリング — お店の雰囲気、伝えたいメニューや商品、発信の頻度をうかがいます
2. 撮影準備 — 撮影する日と、メニュー・商品の準備をご相談します
3. 撮影 / 編集 — お店へ伺って撮影し、写真と動画に仕上げます
4. 納品・発信 — 写真は3〜5営業日、動画は7〜10営業日で納品します。投稿の設計もご相談ください

PLANS｜料金

必要なものだけを、単発でも月額でもお選びいただけます。
まずは A か B で一度お試しいただき、続けられそうなら月額へ切り替える形が多いです。

SPOT｜単発
A｜写真パック お店へ伺い2時間、メニュー・商品・店内を10〜15点 20,000円〜 / 回
B｜動画パック 〜30秒のショート動画5本の編集。調理・接客・新商品のご紹介など（撮影は別途お見積り） 55,000円〜 / 5本
MONTHLY｜月額
C｜発信おまかせ 企画・構成・編集 月5本 ＋ 投稿設計。つくって、届けるところまで 月額 100,000円〜
D｜数字まで見る C ＋ 1本ごとの分析レポート・月次まとめ・改善提案・定例お打ち合わせ 月額 200,000円〜

C と D の違いは、公開したあとに数字を見るかどうかです。
投稿がどれだけ届き、プロフィールを何人が見て、ご来店やお問い合わせにつながったのか。
そこまで一緒に確かめて、翌月の内容に反映するのが D です。
C・D は初回3ヶ月の価格です。4ヶ月目以降は C 225,000円〜／D 400,000円〜 となります。導入・初回の価格は、ご案内できる枠に限りがあります。規定の枠に達した時点で、受付を終了します。
月額プランの動画は、1分前後までの縦型ショート動画です。
お店での撮影は、A の料金（10,000円 / 時間・2時間から）を目安に、内容に応じて別途お見積りします。
本数は、お店のご体制に合わせて調整いただけます。金額はすべて税別・目安です。

RULES

・撮影：お店での撮影は2時間から承ります。営業時間中の撮影もご相談いただけます。ご来店中のお客様が写り込まないよう配慮します。
・修正対応：動画は2回まで無料。写真は撮影当日のモニター確認で調整いたします。
・交通費・お支払い：交通費は別途ご請求します（遠方は別途出張費）。お支払いは月末締め・翌月末払いでご対応可能です。

本数や撮影の範囲は、お店の状況に合わせてご提案します。
「まずは一度試したい」といったご相談も歓迎です。
